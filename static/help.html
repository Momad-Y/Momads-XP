About Momad's XP

Momad's XP is Mohamed Abdelnasser's portfolio, faithfully disguised as a Windows XP desktop. Everything you see runs in your browser — no actual 2001 hardware was harmed.

Source code, documentation and credits live in the GitHub repository. Built on the MIT-licensed win32.run by Bao Nguyen.

Quick tips

  • Double-click desktop icons to open programs.
  • My Computer holds the portfolio — Experience, Projects, Education, Skills, Certifications and Awards.
  • Drag windows by their title bar; resize from any edge.
  • Drop files from your computer into any folder — they are stored in your browser only.
  • Contact Me sends a real email. Yes, really.

Internet Explorer

Yes, it browses. The homepage is Wiby, a search engine for the classic, hand-made web — the kind of pages this operating system grew up with. Hit the Search button or type in the address bar to explore.

Note: many modern websites refuse to load inside another page (their choice, not IE's). If a page stays blank, that's why — the old web on Wiby generally loads fine.
